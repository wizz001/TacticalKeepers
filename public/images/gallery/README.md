# Tactical Keepers gallery assets

Add final photography here using stable names such as:

- `gallery-01.webp`
- `gallery-02.webp`
- `gallery-03.webp`
- `gallery-04.webp`
- `gallery-05.webp`
- `gallery-06.webp`
- `gallery-07.webp`
- `gallery-08.webp`
- `gallery-09.webp`
- `gallery-10.webp`
- `gallery-11.webp`
- `gallery-12.webp`

Then add the corresponding `src` value to the `gallery` array in
`app/gallery/page.tsx`. When `src` is omitted, the designed placeholder is
shown automatically. Layout is controlled separately by each item's `shape`.
